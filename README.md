---

## 🚀 Overview
DevOps Note App is a full-stack MERN (MongoDB, Express, React, Node.js) application deployed on **AWS EC2** using **Docker**, **Docker Hub**, and **Docker Compose**.  
This project demonstrates cloud deployment, container orchestration, and full-stack development.

---

## 🔧 Tech Stack
- **Frontend:** React  
- **Backend:** Node.js + Express  
- **Database:** MongoDB (Docker container)  
- **Deployment:** Docker, Docker Hub, Terraform, Ansible and AWS EC2
